# 📊 Z-Test Hypothesis Testing

## 🔹 Overview
This project demonstrates the application of the **Z-Test**, a statistical hypothesis testing method used to determine whether there is a significant difference between population and sample means.  

The Z-Test is widely used in **business analytics, healthcare, finance, and research** for validating assumptions with sample data.

---

## 🔹 Objectives
- Perform **One-sample** and/or **Two-sample Z-Test**.  
- Test the **null and alternative hypothesis**.  
- Interpret the **Z-score** and **p-value**.  
- Derive meaningful insights through statistical analysis.  

---

## 🔹 Steps Covered
1. Importing libraries & dataset  
2. Data inspection & summary  
3. Applying the **Z-Test formula**  
4. Interpreting the results and hypothesis conclusion  

---

## 🔹 Key Learnings
- Practical application of **hypothesis testing** in statistics.  
- Understanding significance levels (α) and decision making.  
- Hands-on implementation of Z-Test using Python.
